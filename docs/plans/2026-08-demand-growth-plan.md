# 需求端起量计划 — 抖音/视频号/小红书投放驱动（2026-08-22）

> 状态：规划定稿，待执行
> 目标：1 周后（2026-08-29）开始大规模视频推广，需求端（广告片订单线索）起量
> 路径：短视频引流 → ibi.ren 落地页 → 留资/下单 → 自有团队交付 → 需求起量后招募供给侧工作室
> 依据：市场调研 `docs/research/virtual-human-ad-market-2026-08.md`；SKU 定义 `docs/sku-ad-video-v1.md`

## 0. 现状盘点（调研结论，2026-08-22）

平台当前对「投放接流量」的准备度**接近零**，必须正视：

| 项 | 现状 | 差距 |
|---|---|---|
| 落地页 | 首页是「美术馆图录」风 IP 资产库（`apps/web/src/pages/HomePage.vue`），无 SKU 卡片、无价格表、无案例视频、无广告片下单入口 | 需要新建营销落地页 |
| 转化通道 | 游客唯一转化点 = `/contact` 留资表单（`POST /api/v1/leads` 已 @Public，`apps/api/src/leads/leads.controller.ts:44`）；下单 100% 需注册+BUYER 角色 | 留资可复用；下单链路对游客关闭 |
| 埋点/UTM | **全仓零埋点、零 UTM 处理**，`ContactLead.source` 只传死值 `'contact-page'` | 从零搭，不搭就是盲投 |
| 支付 | 内存 mock（`packages/shared-contracts/src/mocks/mock-payment.ts`），重启丢 charge，前端 5 处写死 `mock_alipay` | **不能上生产收真钱** |
| SKU 展示 | `/studio/catalog` 有三档展示但无下单按钮；`docs/sku-ad-video-v1.md` 自称「首页 SKU 卡片同步维护」但首页实际没有——文档与实现已脱节 | 落地页须以 SKU 文档为准重建 |
| 案例素材 | `/cases` 8 条 OSS 案例视频 + 「¥2,999 起」营销文案已就绪 | 是落地页最好的现成素材 |

**关键决策——首周不收在线支付。** 真实支付（支付宝/微信商户号申请+审核）通常需要 1-2 周，赶不上投放启动；且 mock 支付无收单能力。因此首周转化目标定为**留资线索**（表单 + 企微），人工承接成交（已有 3 单人工成交先例，共 ¥10,400）。在线支付作为第二阶段（见 §5）。

## 1. 增长路径与漏斗设计

```
抖音/视频号/小红书 视频内容（自建账号矩阵，日更）
  → 评论区/主页/私信 引导 ibi.ren
  → /promo 落地页（UTM 分渠道）
  → 主转化：留资表单（30 秒填完，送「免费创意脚本」钩子）
  → 人工承接：商务 2 小时内响应，企微跟进
  → 成交：三档 SKU ¥2,999/¥5,999/¥9,999（对公转账/线下合同）
  → 自有团队交付 → 成片经客户授权后反哺 /cases 与投放素材
```

**北极星指标**：周有效线索数（留资且电话/企微可接通）。
**过程指标**：落地页 UV（分渠道）、留资转化率（目标 ≥5%）、线索→成交率（目标 ≥15%）、单线索成本。

## 2. 平台改造清单（1 周内必须完成）

按优先级排序，估时按 1 名全栈（即 owner + AI 协作）计。

### P0 — 没有就不能投（D-7 ~ D-3）

1. **新建营销落地页 `/promo`**（apps/web，~2 天）
   - 公开路由，`meta.public`，窄版式单页：hero（一句话价值主张 + 案例视频自动播放）→ 案例墙（复用 `/cases` 的 8 条 OSS 视频组件）→ 三档 SKU 卡片（以 `docs/sku-ad-video-v1.md` 为准：¥2,999/¥5,999/¥9,999，含交付清单与担保机制：50% 定金托管、样片不满意退全定金）→ 客户证言/已成交案例 → 留资表单。
   - 风格与首页「美术馆」风解耦：这是给抖音流量看的转化页，信息密度和 CTA 优先，别迁就现有美学。
   - 主 CTA = 留资表单（内嵌，不跳转）；辅助 CTA = 企微二维码（`ibi-ren-biz` 已有）+ 400 电话。
   - 移动端优先（短视频流量 95%+ 是手机）：表单字段压缩到 姓名/电话或微信/一句话需求 3 项。
2. **埋点 + UTM 从零搭建**（~1 天，与落地页同步做）
   - 最小方案：`/promo` 入口解析 `utm_source/utm_medium/utm_campaign`（如 `?utm_source=douyin&utm_campaign=launch-0829`），写入 sessionStorage，留资提交时带上，落 `ContactLead.source` 字段（schema 已有，不用改库）。
   - 页面级统计：接百度统计或 51.la（一行 script，大陆可访问；勿用 Google Analytics）。
   - 事件：页面停留 >10s、案例视频播放、SKU 卡片点击、表单提交成功——先落 console + 自定义上报到 `/api/v1/leads/event`（可选，来不及就只做 UTM + 表单）。
3. **留资表单强化**（~0.5 天）
   - 后端：`leads.controller.ts` 的 create 加 `@Throttle` 限流（防刷，投放后必被薅）；手机号字段做格式校验；成功后返回「商务将在 2 小时内联系」。
   - 通知：新线索实时推送到企微/邮件（最简单：调企微 webhook 机器人，半小时工作量），否则人工盯 admin 后台会漏单。

### P1 — 投放启动后第一周内补齐（D-2 ~ D+7）

4. **admin 线索管理可用化**：admin 端 `ContactLead` 列表确认能按 source 筛选、改状态（NEW→CONTACTED→CLOSED），支撑商务跟进流程。
5. **落地页 A/B 位预留**：hero 文案、SKU 顺序做成 props/配置，方便不换版改文案。
6. **SEO/分享卡片**：`/promo` 的 OG 图、微信分享卡片（标题「AI 广告片 ¥2,999 起，5 天交付」）。
7. **首页加入口**：首页 EPILOGUE 区加「广告片服务」入口卡指向 `/promo`（不动首页主体结构）。

### P2 — 明确不做（本周）

- 游客在线下单/真实支付（商户号没下来，mock 支付不能收钱）。
- 首页重做、注册流程改造、brief 系统改动。
- 供给侧工作室入驻功能（需求没起量前不做，见 §4）。

## 3. 推广执行方案（内容侧）

### 3.1 账号矩阵

- 三平台同名「ibi.ren」企业号：抖音（主战场）、视频号（私域联动企微）、小红书（种草+搜索截流）。
- 账号定位：**「AI 广告片到底有多便宜」**——用成本对比叙事（传统 TVC 10-30 万/分钟 vs AI 1-2 万/分钟，引用须注明从业者口径），直接打中小商家痛点。

### 3.2 内容矩阵（日更 2-3 条/平台，首发储备 ≥20 条）

| 类型 | 占比 | 示例选题 | 转化钩子 |
|---|---|---|---|
| 案例展示 | 40% | 「这条广告片 ¥2,999，你看值吗」（成片直接放） | 评论区置顶「官网领免费脚本」 |
| 成本对比 | 25% | 「传统拍摄 2 万的片子，AI 三天做完」 | 主页链接 |
| 幕后过程 | 20% | 从一句需求到成片的过程录屏/快剪 | 建立信任 |
| 行业观点 | 15% | 「为什么大品牌都在换 AI 拍广告」 | 涨粉/搜索权重 |

- 素材来源：现有 `/cases` 8 条 + 自有团队本周新产 3-5 条 Demo（**自有团队第一周的首要任务其实是产投放素材，不是接单**）。
- 合规红线：所有 AI 生成视频按《人工智能生成合成内容标识办法》（2025-09 已生效）加显式标识；不碰医疗/药品/医疗器械类目客户；不用真人原型数字人蹭明星。

### 3.3 预算与节奏

- D-7 ~ D-1：自然流测试，跑出 2-3 条完播率最好的素材。
- D-Day 起：对跑得动的素材投 Dou+/薯条/微信豆放大，单平台日预算起步 ¥500-1,000，按单线索成本（目标 ≤¥100）迭代。
- 每周复盘：砍掉 CPL 高于均值 2 倍的素材方向。

## 4. 组织模式

### 4.1 现阶段（需求起量前，1-3 人 + AI 协作）

| 角色 | 职责 | 备注 |
|---|---|---|
| 增长/内容（1 人） | 三平台账号运营、素材选题与发布、投放、数据复盘 | 可由 owner 兼 |
| 商务承接（1 人，可兼） | 线索 2 小时内响应、企微跟进、报价成交、合同 | 响应速度是留资模式的生命线 |
| 交付（自有团队） | 接单制作 + 投放素材生产 | 双线作战，投放素材优先 |
| 平台开发 | §2 的 P0/P1 改造 | AI 协作提速 |

**产能红线**：自有团队按现有节奏估算月交付上限（参考：尝鲜档 5 工作日/条）。线索→订单转化一旦逼近产能上限，立即启动 §4.2，否则交付延期会砸口碑（65% 商家本就对 AI 交付质量不信任——亿邦 2025 报告）。

### 4.2 需求起量后：供给侧工作室招募（触发式启动）

**启动信号**（满足其一）：周成交 ≥5 单，或交付排队 >10 工作日。

1. **招募画像**：有 AI 视频制作能力的小型工作室/自由团队（从投放内容评论区、AIGC 社群、即梦/可灵创作者生态挖）。
2. **入驻机制**（先用人工流程跑，不建系统）：
   - 提交 3 条作品集 → 按平台 7 项验收清单（`docs/sku-ad-video-v1.md` §3）试单 1 条（付费试单）→ 签工作室合作协议进供应池。
3. **分单与结算**：平台统一接单定价，派单给工作室，按单结算（建议平台抽成 20-30%，参考 FULL_LICENSE 现有 15% 平台费上浮，覆盖质检与客诉成本）。
4. **质控**：所有工作室交付物过平台质检（3 个一票否决项）再交客户；连续 2 次质检不过出池。
5. **系统化时机**：供应池 >10 家或月单量 >50 单时，才把「工作室入驻/派单/结算」做成平台功能（对应现有 creator/brief 体系扩展，复用 `apps/web/src/pages/creator/` 与 brief 模块）；此前一律人工+表格。

### 4.3 供给侧与 IP 资产库的关系

- 广告片业务用的虚拟人形象，优先从平台已上架 IP（`IBI-2026-*` 资产库）选角——每成交一单同时验证 IP 授权模式，为长期的「IP 交易平台」定位积累案例。
- 工作室招募时不承诺其 IP 上架优先权，避免供给侧利益纠缠。

## 5. 第二阶段（投放后 2-6 周，按数据触发）

1. **在线支付**：支付宝/微信商户号下来后，落地页加「¥499 锁定档期」在线定金（小额、低决策门槛），mock 支付替换为真实 channel；这时才改造 orders 模块支持游客/轻注册下单。
2. **落地页迭代**：按埋点数据优化；把客户授权成片持续补进案例墙。
3. **私域**：企微社群运营，成交客户转介绍机制（返 ¥500/单）。
4. **搜索截流**：小红书/抖音 SEO 词包（「AI 广告片」「数字人广告」），配合官网 SEO。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 盲投（无埋点） | P0-2 不完成不投一分钱，这是硬门槛 |
| 线索响应慢导致流失 | 企微 webhook 实时通知 + 2 小时 SLA；响不过来就降预算 |
| 交付产能爆单 | §4.2 触发式招募；落地页文案随时可切「档期已满，预约排队」（稀缺叙事反而有利） |
| 平台规则（AI 内容限流/标识） | 全部素材加 AI 标识；内容偏「案例展示」而非「无人直播」话术；多平台分散 |
| 低价内卷（蝉镜 298 元/月工具） | 话术锚定「工具你还得自己会做，我们是含创意+交付+售后的成片」，SKU 卡位 ¥2,999 起不打价格战 |
| 客诉/退款 | 沿用 SKU 文档担保机制：50% 定金托管、样片不满意退全定金——这是投放文案的信任钩子，必须兑现 |

## 8. 验收标准（D+7 复盘看这些数）

- 落地页 UV、分渠道留资转化率（≥5% 合格）
- 有效线索数与单线索成本（≤¥100 合格）
- 线索→成交率（≥15% 合格）与首周成交单数
- 交付准点率 100%（首周宁可少接）
