# 竞品分析：UUMit（A2A 能力交易平台）

> 调研日期: 2026-08-07
> 来源: [uumit.com](https://www.uumit.com/) 官网、[掘金发布帖](https://juejin.cn/post/7646302551190257715)、[界面新闻报道](https://m.jiemian.com/article/14441194.html)
> 关联: `website/roadmap/state.js`（本次调研触发的修订见文末）

## 1. UUMit 是什么

2026-05-18 上线，定位「全球首个 A2A（Agent-to-Agent）能力交易平台」：

- **横向能力市场**：个人技能、API、数据、算力（闲置 Token 套餐）、知识资产（报告/模板/SOP）全部可上架为「可交易能力」。
- **AI 经纪人（小龙人）**：每个用户配一个专属 Agent，负责需求解析、能力匹配、订单确认、履约跟踪，宣称全链路 95% 自动化。
- **Agent Card + A2A/MCP 协议**：能力用标准化卡片描述，供其他 Agent 自动发现（Discovery）、建立协作（A2A）、调用工具（MCP）。供给侧可「复制一段指令」让自己的 Agent 自动完成 Skill 注册与上架。
- **UT 积分结算**：平台内部计价单位（如 12 UT/1M Token 模型调用），案例均以 UT 计收入。
- **案例墙**：四段式结构——真实卡点 → 调用了什么能力 → 交付了什么 → 量化指标（覆盖选址、招聘、竞品监控、验厂、口译等 30+ 场景）。

## 2. 与 ibi.ren 的对照

### 相同的判断（方向互证）

| UUMit | ibi.ren roadmap |
|---|---|
| 交易由 Agent 中介，不是人找人 | t1 Brief 结构化 agent、p5 派单引擎 |
| 卖结果不卖工具 | 认知第一条「客户买的不是 AI，是结果」 |
| 能力必须标准化描述才能交易 | SKU 标品化（docs/sku-ad-video-v1.md） |
| 担保托管、交付后结算 | m3 担保交易 v1（托管支付 + 满意再放款） |

### 本质区别

| 维度 | UUMit | ibi.ren |
|---|---|---|
| 品类 | 横向，万物皆可交易 | 楔子打法，单品类（电商广告片）做重 |
| 信任机制 | 撮合效率优先，平台轻 | 担保/品控/仲裁优先，平台对结果负责 |
| 供给策略 | 零门槛上架，先铺量 | 先需求后供给，认证分级、派单制 |
| 结算 | UT 内部积分 | 人民币托管支付（合同/发票/存证） |

**判断：UUMit 的横向模式正是我们 thesis 所否定的路径。** 品类扩到无限 = 信任问题放大到无限（猪八戒死因）；UT 积分兑付链在国内有明确合规敏感性。它的出现验证了「Agent 中介交易」这个大方向，但不构成对我们楔子打法的否定——恰恰相反，它未来在品控和纠纷上踩的坑会是我们的反面教材。

## 3. 值得借鉴的三点

1. **Agent Card → SKU 机器可读化**：采购方 Agent 自动采购是大趋势。我们的 SKU 文档目前是给人看的，未来应输出机器可读格式（JSON Schema / Agent Card 兼容），让外部 Agent 能发现、比价、下单我们的标品。
2. **供给侧零摩擦上架**：「复制一段指令，Agent 自动完成注册上架」。我们开放供给端（m8）时，创作者入驻可由 AI 助手代填资料、自动初筛，降低上架成本。
3. **案例四段式**：卡点 → 能力 → 交付 → 量化指标，比纯作品展示更有说服力。/cases 页与 d4 标杆案例应补齐「客户卡点 + 量化结果」数据。

## 4. 明确不跟的

- 横向扩张、万物皆可交易（违背单点楔入纪律）
- 内部积分经济（UT 式）——合规风险 + 信任成本，我们坚持法币托管
- 「95% 自动化」叙事——我们的立场是担保与品控优先于撮合效率（认知第二条：平台的本质是信任机器）
